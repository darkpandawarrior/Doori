**xcodebuild: never pass `-sdk iphonesimulator`.** The `iosApp` scheme includes `MilewayWatch`, whose
`SDKROOT` is correctly `watchsimulator`. `-sdk` overrides SDKROOT for *every* target in the scheme and
produces a failure that looks like a project defect and is not. Use `-destination` alone.

**Drive xcodebuild by simulator UDID, never by name.** Two `iPhone 17` simulators exist (iOS 26.5 and
27.0), so `name=iPhone 17` is ambiguous and a generic destination asks for arm64 *and* x86_64 — a slice
the Kotlin framework does not have. Resolve the UDID first.

**AGP 9.5.0-alpha06 + Roborazzi collide.** AGP registers
`generate<Variant>ComposePreviewRunfiles` for every Compose-enabled variant and hard-fails when that
variant has no unit-test component. AGP itself drops it on library release variants; Roborazzi drops it
on all non-debug variants. The fix lives in the root `subprojects` block, gated on `com.android.base`,
because `beforeVariants` runs in *registration order* and Roborazzi registers after any convention
plugin — a convention-plugin fix silently does nothing here.

**Robolectric 4.17 needs `--add-exports=java.base/jdk.internal.access=ALL-UNNAMED`.** It reaches
`ApplicationSharedMemory.create`, whose `FileDescriptorInterceptor` touches `jdk.internal.access`. That
is an *internal* package, so `--add-opens` cannot fix it.

**Commit messages are screened for a leak-pattern list, matched case-insensitively on `dice`.** The word
*indices* contains it and will get your commit rejected. Write "positions" or "index values". Never
`--no-verify`; the hook is the point.

**`@Preview` in `commonMain` is `androidx.compose.ui.tooling.preview.Preview`.** That is the
multiplatform annotation from Compose Multiplatform 1.10.0 onward; `org.jetbrains.compose.ui.tooling.
preview.Preview` is the legacy path. Verified here: 7 `commonMain` files import the androidx FQN, zero
import the JetBrains one, and they compile.

**detekt baselines are per source set.** `./gradlew detektBaseline` writes *one* file; this repo has 30
and exposes 315 `detektBaseline*SourceSet` tasks. Deleting them all and running the single task destroys
29 of them and makes the finding count look like it collapsed.

**Never run a repo-wide Gradle task from an agent.** 930 tests take ~14 minutes and a long silent
command gets an agent killed for inactivity. Scope to the module and pass `--console=plain`.
